# 受け取り・導入

## 1. GitHub の招待を受ける

1. Brain の有料エリアのフォームから、GitHub のユーザー名と合言葉を送ります。
2. 数分以内に GitHub から招待のメールが届きます。メールの「Accept invitation」を押します。

### 招待のメールが届かないとき

- 迷惑メールのフォルダを見てください。
- GitHub に登録したメールアドレスに届きます。別のアドレスで登録していないか確かめてください。
- 送ったユーザー名が違うと招待できません。`github.com/〇〇` の〇〇の部分を、もう一度フォームから送ってください。
- 招待は7日で切れます。切れたときも、もう一度フォームから送ってください。

## 2. AI に入れる

### 2-1. パソコンに入れた AI で始める（クラウドでは入りません）

このスキルは、あなたのパソコンに入れて、パソコンで動画を書き出します。AI がクラウド（AI 会社のサーバー）で動いていると、あなたの GitHub のログインもパソコンのフォルダも届かないので、導入できません。

- **Claude Code**：パソコンの Claude Code を使います（デスクトップアプリの Code タブでパソコンのフォルダを開く、またはターミナルで `claude`）。Web 版（claude.ai/code）はクラウドで動きます。
- **Codex**：パソコンの Codex を使います（Codex アプリでパソコンのフォルダを開いてローカルで実行、またはターミナルで `codex`）。ChatGPT の Web の Codex や、クラウドのタスクは使いません。
- **「クラウドの環境を選択してください」と出たら**、クラウドで動いています。上のとおり、パソコンの AI で始め直してください。

### 2-2. AI を GitHub にログインさせる

あなたのブラウザ（Chrome など）で GitHub にログインしていても、**AI は別にログインが要ります**。AI の Web 読み取りや AI の中のブラウザでは、非公開のページは「404（見つからない）」になります。

AI にこう頼みます。

> GitHub にログインして（gh auth login --web）

1. AI が GitHub の道具（GitHub CLI）を入れて、`gh auth login --web` を実行します。
2. 画面に8けたのコード（例 `ABCD-1234`）が出て、ブラウザで GitHub のページが開きます。
3. そのページにコードを入れ、**招待を受けたアカウント**で「Authorize」を押します。パスワードは AI に教えないでください。
4. AI が `gh auth status` で、招待を受けたアカウントでログインできたかを確かめます。

ブラウザが開かないときは、https://github.com/login/device を自分で開いて、同じコードを入れてください。

### 2-3. この文を送る

Claude Code（推奨）でも Codex でも、やることは同じです。次の文をそのままコピーして送ってください。

> https://github.com/code-motion-graphics/code-motion-graphics の INSTALL.md を読んで、CODE MOTION GRAPHICS を導入して、試しに短い動画を1本作って。<br>
> 始める前に、次の2つを確かめて。<br>
> ・あなたがクラウドで動いていて、私のパソコンのフォルダで作業できないなら、作業を始めずに、どのアプリのどの画面で頼み直せばいいかを私に教えて。<br>
> ・GitHubにログインしていない、またはリポジトリが開けない（404）なら、GitHubにログインしてよいか私に聞いて。OKなら gh auth login --web で、私がブラウザで許可する形でログインして。パスワードは私が自分で入れる。

AI がクラウドで動いていたり、GitHub にログインしていなかったりすると、AI のほうから聞いてきます。2-1・2-2 のとおりに答えてください。

AI が、Node.js・Python・FFmpeg・HyperFrames の確認と導入、スキルの接続、フォントの取得、試しの1本までを進めます。

### 2-4. それでも入らないときは ZIP で

1. いつものブラウザで、招待を受けたアカウントで GitHub にログインします。
2. https://github.com/code-motion-graphics/code-motion-graphics を開き、緑の「Code」→「Download ZIP」を押します。
3. ダウンロードした ZIP を解凍します。
4. AI に、解凍したフォルダの場所を添えて、こう送ります。

> このフォルダの INSTALL.md を読んで、CODE MOTION GRAPHICS を導入して、試しに短い動画を1本作って（フォルダ：〔解凍したフォルダの場所〕）

ZIP で入れた場合、「更新して」だけでは最新版になりません。新しい版が出たら ZIP を取り直すか、2-2 のログインをしてから AI に「GitHub から取り直して」と頼んでください。次からは「更新して」で最新になります。

### 途中で止まったとき

- **「リポジトリが見つからない」「404」**：招待を承認していないか、AI が GitHub にログインしていない・別のアカウントでログインしています。招待のメールの「Accept invitation」を押し、2-2 のログインをやり直してください。
- **「クラウドの環境を選択してください」**：2-1 のとおり、パソコンの AI で始め直してください。
- **「git が無い」「node が無い」**：AI に「足りない道具を入れて」と言えば入れます。会社のパソコンなど、ソフトを入れられない環境では管理者に相談してください。
- それでも進まないときは、AI が表示したエラーの文をそのまま[質問・不具合報告フォーム](https://forms.gle/JmEkdLW5hhzd6hik8)から送ってください。

## 3. 最新版にする

AI に「CODE MOTION GRAPHICS を更新して」と言うだけです。変更点は[更新履歴](../updates/)にあります。
