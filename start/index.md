# 受け取り・導入

## 1. GitHub の招待を受ける

1. Brain の有料エリアのフォームから、GitHub のユーザー名と合言葉を送ります。
2. 数分以内に GitHub から招待のメールが届きます。メールの「Accept invitation」を押します。

### 招待のメールが届かないとき

- 迷惑メールのフォルダを見てください。
- GitHub に登録したメールアドレスに届きます。別のアドレスで登録していないか確かめてください。
- 送ったユーザー名が違うと招待できません。`github.com/〇〇` の〇〇の部分を、もう一度フォームから送ってください。
- 招待は7日で切れます。切れたときも、もう一度フォームから送ってください。

## 2. AI に入れる

Claude Code（推奨）でも Codex でも、やることは同じです。AI を開いて、この1文を送ります。

> https://github.com/code-motion-graphics/code-motion-graphics の INSTALL.md を読んで、CODE MOTION GRAPHICS を導入して、試しに短い動画を1本作って

AI が、Node.js・Python・FFmpeg・HyperFrames の確認と導入、スキルの接続、フォントの取得、試しの1本までを進めます。

### 途中で止まったとき

- **「リポジトリが見つからない」**：招待を承認していないか、別の GitHub アカウントでログインしています。招待を承認したアカウントで AI の GitHub ログイン（`gh auth login`）をやり直します。
- **「git が無い」「node が無い」**：AI に「足りない道具を入れて」と言えば入れます。会社のパソコンなど、ソフトを入れられない環境では管理者に相談してください。
- それでも進まないときは、AI が表示したエラーの文をそのまま[質問・不具合報告フォーム](https://forms.gle/JmEkdLW5hhzd6hik8)から送ってください。

## 3. 最新版にする

AI に「CODE MOTION GRAPHICS を更新して」と言うだけです。変更点は[更新履歴](../updates/)にあります。
